# REDMI Buds 8 Pro · 华语抒情 EQ 预设

> 给千禧年华语抒情调的一版 10 段 PEQ：以耳机**实测频响**为基准，拟合**哈曼 in-ear 2024 Beta (5128)**，再按歌单画像做定向微调。实测拟合误差 **MAE 0.66 dB / RMSE 0.92 dB**（40 Hz–10 kHz），已写入耳机并通过物理回读校验。

这套参数是为"把男声从伴奏里拎出来，同时保住鼓点体感"这个目标调出来的——不是网上抄的曲线。

---

## 为什么是这一版

| 维度 | 说明 |

## 调音思路

这类歌的共同点：男声主导、编曲偏原声（钢琴/吉他/弦乐）、鼓与贝斯存在感低，人声能量集中在 200 Hz–3 kHz。

所以最怕的是**低频过量**——男声胸声区（150–300 Hz）一旦被抬起来，人声就会糊在伴奏里，听起来"闷"。

| 出手点 | 调整 | 目的 |
|---|---|---|
| 75 Hz | **+3.5 dB** | 底鼓/贝斯体感，点到为止 |
| 250 Hz | **−1.5 dB** | 去掉混响造成的糊 |
| 1200 Hz | **+2.5 dB** | 男声胸腔，人声前移 |
| 2800 Hz | **+2.0 dB** | 咬字清晰 |
| 6500 Hz | **−1.8 dB** | 压齿音（抒情歌的"嘶"声） |
| 11000 Hz | **+2.0 dB** | 空气感，仍在 AAC 可传输范围内 |

## 适用条件

- **耳机**：REDMI Buds 8 Pro（中国版；国际版是否通用未验证）
- **固件**：**≥ 1.3.6.3**。该版本才带 EQ 槽位映射与 TOTA 调音通道，1.3.6.0 会直接 RFCOMM DM
- **工具**：MXGA Buds App（第三方社区工具，本仓库不包含其 APK）
- **前置**：系统蓝牙先连上耳机，App 只识别系统已连接的设备

## 链路事实（先看清再折腾）

| 项 | 结论 |
|---|---|
| 编解码 | AAC 44.1 kHz / 16 bit / 立体声 |
| LDAC | **中国版不支持**，协商结果只有 AAC/SBC |
| 采样率天花板 | 44.1 kHz |

所以那些依赖 192 kHz 母带、18 kHz 空气感的调音方案，在这副耳机上用不出来——本预设的高频处理全部落在 10–13 kHz。

## 文件说明

```
eq/华语抒情-人声版.json    调音包参数（schema + 10 段 bands）
eq/华语抒情-人声版.bin     492 字节耳机槽数据，可导入 App 直接刷写
eq/versions.md            同晚迭代的 6 个版本参数对照
analysis/playlist.md      歌单画像与听感推导
analysis/target-curve.json 拟合目标曲线（72 点）
scripts/build_target.py   目标曲线构造脚本
```

### `.bin` 槽数据格式（逆向所得）

小端序：

```
f32 gain0 | f32 gain1 | u32 bandCount | 30 × (u32 type, f32 gain, f32 freq, f32 q)
```

合计 12 + 30×16 = **492 字节**，未使用的槽位填 0。

## 复现

1. 安装 MXGA Buds App（≥ 1.2.55）
2. 系统蓝牙连上耳机，确认固件 ≥ 1.3.6.3
3. App 首页 → 文件导入 → 选择 `eq/华语抒情-人声版.bin`
4. 写入耳机，等待物理回读校验通过
