## 特征

- 男声占绝对主导，编曲偏原声（钢琴、吉他、弦乐）
- 鼓与贝斯存在感低，人声能量集中在 200 Hz–3 kHz
- 夹杂少量民谣与说唱

## 对调音的推论

1. 最怕低频过量：150–300 Hz 抬起后，人声会糊在伴奏里
2. 人声清晰度比低频更重要：1200 Hz 与 2800 Hz 是关键出手点
3. 齿音突出，6–7 kHz 需适度压制
4. 空气感只能在 10–13 kHz 做，AAC 44.1k 之上没有内容

## 验收曲目

1. 方大同《愛愛愛》—— 人声与吉他的分离度
2. 陈奕迅《單車》—— 男声胸声厚度与齿音
3. 汪苏泷《万有引力》—— 鼓点弹性
